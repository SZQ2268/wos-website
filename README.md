### 如何部署

---

可以使用很多种方式，
但是因为这个网页太简单了，
所以你可以使用直接使用浏览器打开:-)

如果你真的要部署也可以，我们这里以NPM举例:
```bash
npm run build
npx http-server dist -a 127.0.0.1 -p 8080
```
然后浏览器输入`http://127.0.0.1:8080`，可能会报毒，但那是正常的(Http而不是https就会这样)
